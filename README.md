# ATRI 桌面端

ATRI 的桌宠：她站在你的桌面上，点一下会有反应，双击就能和她说话，到点的提醒她会说出来。

这只是个外壳（Electron）。聊天、记忆、形象模型都在你自己的 ATRI 服务器上，这里不存任何密钥，也不带模型文件：
应用打开服务器上的桌宠页（`/atri/pet`），放进一个透明、没边框、总在最前的小窗口。

## 安装

在 [Releases](https://github.com/YuxiangLin-kaslana/atri-desktop/releases) 下载 `ATRI-Setup-x.y.z.exe`，双击安装（只支持 Windows）。
安装包没有代码签名，第一次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”→“仍要运行”。

第一次打开会让你登录一次（和网页版同一个账号）。默认连 https://atri.yuxianglin.xyz；要连别的 ATRI 服务器，在托盘菜单“服务器地址…”里改。

## 怎么用

- 按住她拖动，可以把她挪到屏幕任何地方；她身边透明的地方点得到后面的窗口。
- 在她身上滚动鼠标滚轮，随意放大缩小；右键菜单“大小”里也有几档。
- 点她一下她会有反应；双击她，或者按 `Ctrl+Alt+A`，下面会出来输入框，说完按回车。
- 她的回答出现在头顶的气泡里；太长或者做了文件，点“在聊天窗口看全文”。
- 右键她或者点托盘图标：打开聊天窗口、调大小、换形象、总在最前、开机启动、服务器地址、检查更新、退出。
- 把文件拖到她身上，她会收下，和你下一句话一起看。
- 把她藏起来时，提醒和她主动说的话用 Windows 通知弹出来，点一下叫她出来。

## 语音

- 她的话默认念出来（声音和语速在网页“设置”里选）；右键菜单“念出她的话”可以关。
- 双击她，输入框旁边点 🎤 说一句，说完停一下就发出去。
- 右键菜单勾上“语音对话”就一直听：直接说话，她说话时你开口她会停下。开着时她头顶挂着“🎤 在听”，点它就关；每次打开应用都是关的。
- 听写和合成都在你的 ATRI 服务器上做；应用只要麦克风权限（不要摄像头）。

## 让她看屏幕（默认关）

右键她或托盘菜单里勾上“让她看屏幕”，她就像坐在旁边一起看：每隔半分钟看一眼，屏幕变了才把截图发到你的 ATRI 服务器给她看
（服务器不保存截图），看到报错、你卡住了、或者你在玩游戏时，可能说一句；这时你和她说话会附上当时的截图。

- 开着的时候她头顶一直挂着“👀 在看你的屏幕”，点它或者在菜单里取消勾选就关掉；每次打开应用都是关着的；锁屏时不看。
- 看屏幕只是看；要她动手，见下面“允许她用电脑”。

## 允许她用电脑（默认关）

托盘菜单里勾上“允许她用电脑”（第一次会问你确认），之后你在聊天里让她“在电脑上打开 B 站搜一下 Live2D”这类事，
她会在你的电脑上一步步做：看一眼屏幕 → 点鼠标、打字、按键、用默认浏览器打开网页 → 再看一眼，直到做完，做完在聊天里告诉你。

- 只做你让她做的事。她自己想上网、注册账号，用的是她自己在服务器上的浏览器和她自己的账号，不碰你的电脑和你的账号。

- 她在用的时候屏幕顶上一直挂着红色的“ATRI 正在用电脑”。你一碰鼠标或键盘她马上停（这就是急停），锁屏时也停。
- 付钱、买东西、发消息/评论/帖子、删东西、输密码、装卸软件、在终端里执行命令，她会先在头顶气泡里问你，点“同意”才做；
  密码和验证码她不填，让你来。
- 截图会发到你的 ATRI 服务器给她看，保留 7 天，方便回看她做了什么。
- 屏幕坐标、点击和按键由应用自带的一个 PowerShell 小脚本做（`src/hands.ps1`），它只在勾上时运行。

## 更新

应用启动时和每隔 4 小时检查一次这个仓库的 Release，有新版就在后台下载，退出时自动装上（托盘菜单里也可以马上重启更新）。

## 开发和发布

```bash
npm install
npm start              # 本地运行
npm run dist           # 在 Windows 上打安装包到 dist/
```

发布：改 `package.json` 里的版本号，提交，推一个同名标签（比如 `git tag v0.1.1 && git push origin v0.1.1`）。
GitHub Actions 会在 Windows 机器上打包，并发到 Release。
